# C语言 电路节点电压法求解器
> 电路原理课程作业，使用**节点电压法**，结合高斯消元求解线性方程组，计算电路节点电压、各电阻支路电流。

## 项目简介
本程序采用节点电压法分析直流电阻电路。
- 节点编号规则：**0代表参考地（电位=0V）**
- 输入：节点数量、电阻（两端节点+阻值）、电流源（流入节点+电流）
- 核心算法：高斯消元法求解线性方程组
- 输出：各独立节点电压，每一条电阻支路的电流

## 功能
- 建立节点电导矩阵
- 高斯消元求解增广矩阵
- 输出全部独立节点电压
- 自动计算每条电阻支路电流
- 最大支持10个独立节点，50个电阻

## 开发环境
- Windows
- Visual Studio / GCC
- C语言

## 编译运行
1. 源码文件：`main.c`
2. VS编译：已添加 `#define _CRT_SECURE_NO_WARNINGS`，消除安全警告
3. GCC编译命令：
```bash
gcc main.c -o circuit.exe
./circuit.exe
使用说明输入规则
输入独立节点总数量（不含参考地 0）
输入电阻数量，依次输入每个电阻：p q R

p,q 为电阻两端节点编号，0 代表接地


输入电流源数量，依次输入每个电流源：node current

node：电流流入的节点；电流正向为流入节点


输出
各独立节点电压 (V)
每个电阻支路电流 (A)，电流方向：节点 p → q
核心原理
根据 KCL 建立节点电压方程，构造电导矩阵 G 和电流向量 I
组装增广矩阵，高斯消元求解线性方程组 \(G \cdot U = I\)
得到节点电压后，利用欧姆定律 \(I_R=(U_p-U_q)/R\) 计算支路电流
限制
仅支持直流电阻电路 + 独立电流源，不支持电压源、受控源
MAX_N=10（最多 10 个独立节点）；MAX_R=50（最多 50 个电阻）
没有做奇异矩阵判断（电路无解 / 无穷多解时会除零崩溃）
适用场景电路原理课程设计、节点电压法算法练习。plaintext
